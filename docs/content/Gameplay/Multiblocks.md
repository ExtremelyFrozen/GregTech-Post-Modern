# 多方块预览、搭建与检测

在 JEI 或 EMI 中查看主机物品的配方，可以打开多方块结构页。手持终端可以在已放置的主机上规划搭建或拆除，并在世界中显示投影。


## 在 JEI 或 EMI 中查看结构

1. 打开多方块的结构页。多个命名结构可以分别选择，也可以组合查看。
2. 打开 **等级与尺寸**，选择可用的舱室等级、方块组、结构样式和尺寸。可调数字表示相应轴上实际占用的格数。选项由当前结构提供，例如蒸馏塔可以改变层数。
3. 使用聚焦、可见层和舱室高亮查看内部结构。点击模型中的方块会显示该位置允许使用的候选。**选择方块**面板用于切换有等级候选的方块组。
4. 用材料栏两端的按钮翻页。材料栏包含主机和当前结构组合所需的材料，悬停可查看数量及对应子结构。

每次重新打开结构页时，结构选项从默认值开始。结构页使用独立的预览场景，材料用途也按当前预览解析。


## 用终端搭建或拆除

1. 将多方块主机放到目标位置并调整朝向。手持终端右击主机完成绑定，然后对空右击打开界面。打开时，玩家和主机位于同一维度，距离在八格以内，主机所在区块已加载，且玩家拥有操作权限。
2. 选择要处理的结构。选中需搭建的结构时，它依赖的结构会一并加入搭建批次。切换**搭建**或**拆除**，并按需要设置尺寸、样式、等级和翻转。只有定义允许镜像的机器才提供翻转。
3. 通过**显示**或**隐藏**控制所选结构在主机位置的世界投影。模型上的材料提示显示目标方块及规划动作，材料栏会标出缺少的数量。全屏视图保留结构选项和材料栏。
4. 检查当前预览后点击**执行**。服务端按当前世界和材料重新验证方案，执行后显示本批放置与拆除的数量。

| 选项 | 作用 |
| --- | --- |
| 替换 | 允许搭建方案替换已占用且可操作的目标方块。关闭时，仍会利用已满足该位置要求的方块。 |
| 无舱室 | 默认开启。优先使用原有的非舱室候选填充可替换位置，只有舱室可用的位置留空。将其关闭可以在方案中选用舱室。 |
| 拆除 | 以所选结构的世界位置为目标，保留绑定主机。可以借助投影对齐实际结构的朝向、尺寸和样式。 |

终端保存最近的主机绑定与全局选项。搭建扣料先使用玩家物品栏，再按顺序使用可用的扩展材料来源。安装 AE2 时，玩家携带已绑定且能访问网络的 AE2 无线终端即可从对应 ME 网络取料。返还拆除材料时按来源顺序反向处理。


## 检测多方块

主机在相关方块发生变化时安排结构检测。打开主机界面，点击主页左下角的**检测结构**可手动检查未成型的结构。按住 Shift 点击会安排一次优先的完整检测，也可用于已成型的主机。检测期间按钮保持按下状态。

安装 Jade 时，将准星移到主机上可查看各命名结构的成型状态。未成型的结构显示最接近匹配的候选所缺少的必要条件，包括适用的坐标、方块、部件等级或数量。结构尚未检测时，Jade 显示待检测状态。
