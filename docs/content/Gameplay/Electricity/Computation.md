# 算力与装配线研究

算力以 CWU/t 计量。研究站使用算力推进研究，将成果写入数据物品。装配线通过数据访问仓或数据银行取得对应研究数据。


## 从研究配方取得数据

1. 在配方查看器查找目标装配线配方的研究要求。扫描仪处理扫描类研究，研究站处理需要算力的数据球和数据模块研究。
2. 使用研究站时，将物品支架的正面朝向研究站主机正面的反方向，完成结构并供电。按研究配方在支架中放入样品和对应的数据物品。
3. 用光缆连接高性能计算阵列（HPCA）的算力数据源仓与研究站的算力数据靶仓。为阵列装入计算和散热组件并供电。
4. 让研究站达到配方要求的最低 CWU/t。配方消耗累计算力，获得更多算力时进度增加得更快。供给低于最低值时，研究站等待算力并保留进度。
5. 把写入研究数据的物品放入装配线的数据访问仓。通过数据银行共享时，把数据物品放入银行的数据访问仓，供电后用光缆把数据银行的光学数据发送端接到装配线的光学数据接收端。


## 路由算力

单组 HPCA 可直接向研究站供给算力。网络交换机可汇集多个来源并把算力分配给多个目标。HPCA 通过交换机桥接时需要桥接组件，交换机也需要供电。算力仓的方向和端口类型决定相邻方块或光缆能否形成连接。

网络每刻先分配消费端的最低需求，再用剩余算力满足额外需求。研究站界面显示供给能力和当前进度，便于区分接线、供电和最低算力不足。

算力使用算力数据仓，研究数据使用光学数据仓。两者均可通过光缆传输。 [配方与研究定义](../../Modpacks/Recipes/Adding-and-Removing-Recipes.md)
