# 欢迎阅读 GregTech Post Modern 1.21.1 文档！

- 玩法指南介绍机器、电力、矿脉和终端。 [玩法指南](Gameplay/index.md)
- 整合包文档介绍数据包、资源包和附属模组。 [整合包制作](Modpacks/index.md)
- 开发文档介绍当前的结构与配方模型、字段同步和运行环境。 [开发文档](Development/index.md)
